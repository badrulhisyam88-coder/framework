# Templates

Canonical templates for each content type. **Copy to the appropriate folder before editing — never write content directly in this directory.**

| Template | Destination | Naming Convention |
|---|---|---|
| [template-finding.md](template-finding.md) | `findings/<category>/` | `FIND-<CAT>-<YYYYMMDD>-<NNN>_<slug>.md` |
| [template-lab-walkthrough.md](template-lab-walkthrough.md) | `labs/` | `YYYYMMDD_<platform>_<challenge-slug>.md` |
| [template-remediation.md](template-remediation.md) | `remediation/` | `remediation-<category>-<slug>.md` |
| [template-blue-team.md](template-blue-team.md) | `blue-team/` | `YYYYMMDD_blue_<slug>.md` |
| [template-attack-chain.md](template-attack-chain.md) | `attack-chains/` | `YYYYMMDD_chain_<slug>.md` |
| [template-journal.md](template-journal.md) | `journals/` | `YYYYMMDD_journal.md` |
| [template-concept.md](template-concept.md) | `concepts/` | `concept-<slug>.md` |
| [template-report.md](template-report.md) | `reports/` | `YYYYMMDD_report_<scope-slug>.md` |

All naming conventions and frontmatter rules are defined in [../EXPORT_STANDARDS.md](../EXPORT_STANDARDS.md).
